For the protein P22270 in DROME, I am convinced that it is not a multi-GPCR.
 It is, however, a distant homologue of A0A7R9CV33 (which is a mGPCR). 
 It seems to be that this receptor doubled in their evolutionary context,
 and studying this could give insight into when/why it duplicated in the genome etc.

These receptors show extreme similarity in their structure, and their disordered regions are present,
so I guess there is some point in speciation where this protein doubled and evolved to be a mGPCR!
